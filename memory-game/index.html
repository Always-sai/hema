How to play

Three steps, no rules to memorise. The whole game fits in a single screen.

1

Pick a difficulty

Easy uses six pairs, medium eight and hard twelve. Changing the level deals a fresh board and resets the clock.

2

Flip two cards

Every pair of flips counts as one move. Matching symbols stay face up; a mismatch turns back over after a moment.

3

Clear the board

Find all the pairs to stop the timer. Fewer moves wins — if you tie your own record, the faster time takes it.

Play notes

Small habits that make a memory board feel a lot easier.

Say the position out loud

Naming a card and where it sits — “owl, top right” — anchors it in memory far better than a quick glance.

Work in a sweep

Read the board left to right, row by row. A consistent order stops you from re-checking the same cards twice.

Chase the move count

Time is a nice number, but moves are the real score. Every pair you already know is a move you can save.

Take the pause

When a mismatch flips back, use that half second to lock in both positions before you reach for the next card.
